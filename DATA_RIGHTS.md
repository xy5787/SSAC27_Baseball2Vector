# Third-party data

The inputs come from [FanGraphs MLB batting leaderboards](https://www.fangraphs.com/leaders/major-league). This repository does not grant rights to those inputs and contains no raw exports or row-level analysis datasets. The MIT license covers project-authored code, not third-party data.

FanGraphs [Terms of Service](https://www.fangraphs.com/about/terms-of-service) contain restrictions on unauthorized copying and further distribution. The terms page returned HTTP 403 during the review; the indexed text did not establish a research-repository redistribution permission. The supported member export described on the [contact page](https://blogs.fangraphs.com/contact/) should not be interpreted as permission to redistribute downloaded files. Obtain authorized access and check the applicable terms yourself; request clarification from FanGraphs if redistribution is needed.

The release provides source links, acquisition settings, an input schema, snapshot hashes, preprocessing and analysis code, and aggregate research outputs. It does not assert that this approach has already been approved by SSAC. The current [competition page](https://www.sloansportsconference.com/research-paper-competition) requires public supporting materials and data. A [historical SSAC23 announcement](https://www.sloansportsconference.com/mit-news/ssac23-research-paper-competition) allowed source links, but current-year acceptance should be confirmed with the organizers.
